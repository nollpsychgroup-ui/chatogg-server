# Temp score for the previs animatic

- `temp-score.mp3`: music only (1M0 hum bed + 1M1–1M8), ~9:30, 24 kHz mono. A rough temp, not a final.
- `temp-mix.mp3`: the same music plus temp sound-design placeholders (rails, relay ticks, door chimes, the inhale in the blackout), at the same gain. Use this one to cut the animatic.
- `temp-sfx.mp3`: the temp sound-design stem alone. `temp-score` + `temp-sfx` = `temp-mix`, all at the same gain.
- **`temp-mix-48k.flac`: the file for the TA to mux into the animatic.** 48 kHz stereo, lossless, 9:30, starting at frame 0 of the cut (24 fps). The 48 kHz FLAC stems (`temp-score-48k.flac`, `temp-sfx-48k.flac`) are generated by the script but not committed, to keep the repo small.
- **Levels are absolute; mux at unity gain with `film/previs/voice/scratch-voice.flac`.** The asleep bed is −48 dBFS RMS, about 20 dB under normal speech. The brownout reaches about −31 dBFS RMS and the blackout is digital zero. Every line stays ≥ 8 dB over the bed: the renderer measures each clip in the scratch voice and ducks the bed under it. Mark's murmurs are exempt (max 4 dB of duck), because they are meant to sit at the edge of audibility.
- `reference-mix-with-scratch-voice.mp3`: a listening reference only (temp mix + scratch voice at unity). The TA muxes the two files separately. It is written only when the scratch voice is on the same clock as `cues.json`.
- **Temp SFX** = rails, relay ticks, door chimes, the inhale, and a **GROAN placeholder** for each waking (lie 1 faint, lie 2 closer, the brownout from the walls, the hungry swell, one exhale per Advance tick, receding through the relights). Sound design replaces all of it.
- **Dialogue windows** come from `film/previs/voice/scratch-voice-lines.json` (Screenwriter; the real placed clips, with measured levels), falling back to the `dialogue` array in `camera/cues.json`. Inside each line the Undertone and cellos duck 4 dB and the rails 3 dB, and no music enters. The DP's build refuses any Advance tick or relight inside a line.
- `temp-sync-report.txt`: every cue and event time the render used.
- `render_temp_score.py`: renders both from the cue timeline: `python3 render_temp_score.py [cues.json]` (numpy, ffmpeg; ~50 s).

**Sync source:** the renderer reads `film/camera/cues.json` (DP, shared with 3D/TA; now live). It also takes the panel partials, the breathing depth/period/on/off and cue 5's main/sympathy panels from there. `cues-provisional.json` is the fallback the DP's file was built from, and is now superseded: cue ids match DP cues 0–8 and sub-cues 7.x/8.x, panels are P1 (above Noor) to P12 (far end), and times are seconds from the first frame. If picture timing changes, re-time the cue file and re-run. The score follows automatically.

Rules the render enforces: the blackout is digital zero (only the SD inhale in its last 1.5 s, in the temp mix), the Advance ticks are checked against the ≥ 8 s rule, the hum holds to the cut, the release clears 1 s before Kai's phone dims, and the credits are silent.
